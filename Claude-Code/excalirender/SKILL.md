# Excalirender — Export & Render Excalidraw Diagrams

This skill converts `.excalidraw` diagram files into PNG, SVG, and PDF using the `excalirender` CLI tool. It also supports visual diffs, combining multiple diagrams, metadata inspection, and live preview.

## When This Skill Applies

- User wants to **export/convert/render** an `.excalidraw` file to PNG, SVG, or PDF
- User wants to **compare two versions** of a diagram visually
- User wants to **combine multiple diagrams** into a single image
- User wants to **inspect metadata** of an `.excalidraw` file
- User wants a **live preview** while editing a diagram
- User just created a diagram with the `excalidraw-diagram-generator` skill and wants a rendered output

## Prerequisites

The `excalirender` CLI must be installed. Check with:

```bash
excalirender --version
```

If not installed, the user can install it via one of these methods:

- **Docker**: `docker run --rm -v "$(pwd):/data" -w /data jonarc06/excalirender <file>`
- **From source (macOS/Linux)**: Clone https://github.com/JonRC/excalirender, run `bun install`, and create a shell alias
- **Native Linux binary**: `curl -fsSL https://raw.githubusercontent.com/JonRC/excalirender/main/install.sh | sh`

## Workflow

### 1. Identify the User's Goal

Map the user's request to the right excalirender command:

| User Goal | Command | Example |
|-----------|---------|---------|
| Export diagram as image/PDF | `excalirender <file>` | "Convert my diagram to PNG" |
| Export in a specific format | `excalirender <file> -o output.svg` | "Save this as SVG" |
| Export at higher resolution | `excalirender <file> -s 2` | "Export at 2x resolution" |
| Export with dark theme | `excalirender <file> -d` | "Render in dark mode" |
| Export with transparent bg | `excalirender <file> --transparent` | "PNG with no background" |
| Export a specific frame | `excalirender <file> -f "Frame Name"` | "Export just the login flow frame" |
| Batch convert a folder | `excalirender -r <dir>` | "Convert all diagrams in this folder" |
| Compare two diagram versions | `excalirender diff <old> <new>` | "Show me what changed" |
| Combine diagrams into one image | `excalirender combine <files...>` | "Put these diagrams side by side" |
| Inspect diagram metadata | `excalirender info <file>` | "What's in this excalidraw file?" |
| Live preview while editing | `excalirender watch <file>` | "Preview this diagram in my browser" |

### 2. Pre-render: Fix Bound Text (Critical Step)

Before rendering, check whether the `.excalidraw` file has text stored directly on shape elements (rectangles, ellipses, diamonds) rather than as separate bound text elements. This is common in files generated by the `excalidraw-diagram-generator` skill and some other tools. excalirender cannot render text in this non-standard format, so labels inside shapes will be silently missing from the output.

**Always run the fix script before rendering:**

```bash
python3 <skill-dir>/scripts/fix-bound-text.py <input.excalidraw> -o <fixed.excalidraw>
```

Then render the fixed file instead of the original. The script is safe to run on files that already use the standard format — it will report "Fixed 0 elements" and produce an identical copy.

If the script reports fixing >0 elements, render the fixed file. If it reports 0, you can render the original directly.

### 3. Run the Appropriate Command

#### Basic Export (most common)

The output format is inferred from the file extension in `-o`:

```bash
# PNG (default if -o is omitted)
excalirender diagram.excalidraw -o diagram.png

# SVG
excalirender diagram.excalidraw -o diagram.svg

# PDF
excalirender diagram.excalidraw -o diagram.pdf
```

If the user doesn't specify a format, default to **PNG** — it's the most universally useful.

**Common options to consider:**

| Option | Flag | When to Use |
|--------|------|-------------|
| Scale | `-s <number>` | User wants higher resolution (e.g., `-s 2` for 2x). Recommend for presentations or print. |
| Dark mode | `-d` | User mentions dark theme, dark background, or dark mode |
| Transparent background | `--transparent` | User wants no background fill (useful for overlaying on other content) |
| Custom background | `-b "#hex"` | User specifies a particular background color |
| Specific frame | `-f "name"` | Diagram has multiple frames and user wants just one |

**Example — high-res dark mode SVG:**
```bash
excalirender diagram.excalidraw -o diagram.svg -s 2 -d
```

#### Batch Export

Convert all `.excalidraw` files in a directory:

```bash
# All files in current dir → PNG
excalirender -r .

# All files in a directory → specific output folder
excalirender -r ./diagrams -o ./exports
```

#### Visual Diff

Compare two versions of a diagram. Useful when the user has updated a diagram and wants to see what changed:

```bash
# Static diff image
excalirender diff old.excalidraw new.excalidraw -o diff.png

# Animated GIF diff (toggles between old and new)
excalirender diff old.excalidraw new.excalidraw -o diff.gif --delay 2000

# SVG diff
excalirender diff old.excalidraw new.excalidraw -o diff.svg
```

**Diff-specific options:**
- `--hide-unchanged` — only show elements that changed (reduces visual noise)
- `--no-tags` — hide the added/removed/modified status labels
- `--delay <ms>` — frame delay for GIF output (default 1000ms)

#### Combine Diagrams

Merge multiple diagrams into a single image — helpful for documentation, comparisons, or overview pages:

```bash
# Side by side (horizontal, default)
excalirender combine a.excalidraw b.excalidraw -o combined.png

# Stacked (vertical)
excalirender combine a.excalidraw b.excalidraw -o combined.png --layout vertical

# With labels and custom gap
excalirender combine a.excalidraw b.excalidraw c.excalidraw -o overview.png --labels --gap 60
```

#### Metadata Inspection

Get information about a diagram without rendering it:

```bash
# Human-readable output
excalirender info diagram.excalidraw

# JSON output (useful for scripting)
excalirender info diagram.excalidraw --json
```

This shows element counts, dimensions, and other metadata. Use this when the user wants to understand what's inside a file before deciding how to render it.

#### Live Preview (Watch Mode)

Start a local server that auto-renders and live-reloads in the browser whenever the file changes:

```bash
# Basic watch
excalirender watch diagram.excalidraw

# Custom port, dark mode
excalirender watch diagram.excalidraw --port 8080 -d

# Watch a diff (two files)
excalirender watch old.excalidraw new.excalidraw
```

Use `--no-open` if the user doesn't want the browser to open automatically.

#### Piping (stdin/stdout)

excalirender supports piping, which is useful for chaining with other tools or when working with generated diagrams:

```bash
# Pipe excalidraw JSON from stdin
cat diagram.excalidraw | excalirender - -o output.png

# Pipe output to stdout
excalirender diagram.excalidraw -o - > output.png

# Full pipe with format specification
cat diagram.excalidraw | excalirender - -o - --format svg > output.svg
```

This is particularly useful when integrating with the `excalidraw-diagram-generator` skill — you can generate a diagram and immediately render it without an intermediate file.

### 4. Verify and Report

After running the export:

1. **Confirm the output file exists** and report its path and size
2. **Open or display the result** if possible (e.g., `open output.png` on macOS)
3. **Suggest follow-ups** if relevant:
   - "Want me to also export as SVG?"
   - "I can increase the resolution with `-s 2` if this is for a presentation"
   - "Want me to try dark mode?"

## Integration with excalidraw-diagram-generator

When a user creates a diagram using the `excalidraw-diagram-generator` skill and then asks to render/export it, this skill takes over. The workflow is:

1. The diagram generator creates the `.excalidraw` file
2. This skill renders it to the requested format using `excalirender`

If the user asks to "create a flowchart and export it as PNG" in a single request, the diagram generator handles creation and this skill handles the export — both should be used in sequence.

## Troubleshooting

| Issue | Likely Cause | Fix |
|-------|-------------|-----|
| `command not found: excalirender` | Not installed | See Prerequisites above |
| Text missing inside shapes | Non-standard bound text format | Run `fix-bound-text.py` before rendering (see Step 2) |
| Empty/blank output | File has no visible elements | Run `excalirender info <file>` to inspect |
| Output too small | Default scale is 1x | Use `-s 2` or `-s 3` for higher resolution |
| Wrong colors in export | Dark/light mode mismatch | Try with or without `-d` flag |
| Frame export shows nothing | Wrong frame name | Run `excalirender info <file>` to list frames |
| Fonts look different | Missing system fonts | Expected behavior — excalirender uses its bundled rendering engine |
